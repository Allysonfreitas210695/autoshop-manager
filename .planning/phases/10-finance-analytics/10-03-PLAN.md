<threat_model>

## Trust Boundaries

| Boundary                                     | Description                                                                  |
| -------------------------------------------- | ---------------------------------------------------------------------------- |
| Browser form → Server Action                 | Dados do formulário de transação (tipo, valor, data, etc.) não confiáveis    |
| DataTable onRowClick → EditTransactionDrawer | Row data vem do Server Component — confiável mas deve ser imutável no client |

## STRIDE Threat Register

| Threat ID  | Category               | Component                                                    | Disposition | Mitigation Plan                                                                                       |
| ---------- | ---------------------- | ------------------------------------------------------------ | ----------- | ----------------------------------------------------------------------------------------------------- |
| T-10-03-01 | Tampering              | window.confirm em deleteTransactionAction                    | accept      | Confirmação nativa é suficiente para delete acidental; sem dado sensível no cliente                   |
| T-10-03-02 | Elevation of Privilege | Drawers chamam actions sem verificação de ID ownership       | mitigate    | authActionClient valida sessão; sem acesso multi-tenant nesta fase — qualquer autenticado pode editar |
| T-10-03-03 | Spoofing               | transactionId passado do client para updateTransactionAction | mitigate    | Zod valida z.uuid() no server action; input inválido é rejeitado antes do db.update                   |

</threat_model>
