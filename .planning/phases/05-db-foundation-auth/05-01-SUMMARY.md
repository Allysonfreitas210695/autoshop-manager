## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 - Blocking] Drizzle journal mismatch caused db:migrate to hang**

- **Found during:** Task 3 (apply migration 0003)
- **Issue:** Migration 0002 was previously applied to the Neon DB via `drizzle-kit push` (bypassing the journal). drizzle-kit's journal only had 0000 and 0001 as applied. When db:migrate ran, it tried to re-apply 0002 (CREATE TABLE statements) against already-existing tables, causing a silent hang.
- **Fix:** Computed the SHA-256 hash of `0002_flat_reavers.sql` and inserted it into `drizzle.__drizzle_migrations` with the correct timestamp, matching drizzle-kit's journal format. This caused drizzle-kit to skip 0002 and apply only 0003 on the next run.
- **Files modified:** None (DB-side fix only — drizzle.\_\_drizzle_migrations table)
- **Verification:** `npm run db:migrate` exited 0; `SELECT unnest(enum_range(NULL::purchase_order_status))` returns 5 values including 'confirmed'
- **Committed in:** `5f6f657` (Task 3 commit)
