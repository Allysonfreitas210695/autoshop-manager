| Threat ID | Category          | Component                                        | Disposition | Mitigation Plan                                                                                                                                              |

| T-08-01   | Tampering         | createOrderAction stock decrement                | mitigate    | serviceId validated as `z.uuid().optional()`; UPDATE uses parameterized Drizzle `sql` template — no injection; atomic subtract avoids read-modify-write race |

| T-08-03   | Denial of Service | unbounded negative stock                         | accept      | D-04: negative stock allowed by design; low-stock alerts are the warning mechanism, no floor guard                                                           |
| T-08-04   | Tampering         | partial write (insert succeeds, decrement fails) | mitigate    | `db.transaction()` rolls back all statements if any throws — no orphaned decrement/insert                                                                    |
