<objective>
Enforce the SEC-01 password policy (D-08): a shared Zod `passwordSchema` (min 8, at least one letter and one number) reused by register + reset on client AND server, mirrored by Better Auth `minPasswordLength: 8`. Login keeps `min(8)` only so the complexity policy is not leaked at login. Additionally close the FLAGGED reset-link logging gap by guarding the `console.log` so the sensitive reset URL never reaches production logs.

Purpose: Server is the authoritative validation boundary; client Zod is feedback only. Better Auth has no native complexity validator hook, so the letter+number rule must live in Zod on both sides.
Output: Updated `src/_schemas/auth.ts`, new `src/_schemas/auth.test.ts`, updated `src/_lib/auth.ts`.
</objective>
